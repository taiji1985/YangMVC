🚀 YangMVC 方法参数自动映射

无需手动获取参数，让代码更简洁优雅

✨ 核心特性

YangMVC支持将HTTP请求参数自动映射到控制器方法的参数中。只需在pom.xml中添加-parameters编译参数即可使用。

传统方式 vs 自动映射：

// ❌ 传统方式
public void login() {
    String username = param("username");
    String password = param("password");
}

// ✅ 自动映射
public void login(String username, String password) {
    // 直接使用参数
}

⚠️ 注意事项

  • 必须在pom.xml中添加-parameters编译参数
  • 参数名必须与HTTP请求参数名完全一致（区分大小写）
  • 如果参数不存在，自动映射的参数值为null
  • 建议对可能为null的参数进行判空处理
  • 支持类型：String、Integer、Long、Double、Boolean等基本类型
