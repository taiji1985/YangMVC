## 框架介绍

### 什么是YangMVC？

YangMVC是一个轻量级的Java MVC框架，专为快速开发Web应用而设计。它具有以下特点：

- **简单易用**：零配置，约定优于配置
- **动态ORM**：无需生成实体类，直接操作数据库表
- **链式API**：流畅的查询语法，代码简洁优雅
- **Spring Boot支持**：提供Spring Boot Starter，快速集成
- **高性能**：基于ReflectASM的字节码增强，执行效率高

### 核心组件

```
YangMVC
├── Controller    # 控制器基类 - 处理HTTP请求
├── Model         # 数据模型 - ORM映射
├── DBTool        # 数据库工具 - 执行查询
├── LasyList      # 延迟加载列表 - 链式查询
└── MVCFilter     # 核心过滤器 - 请求分发
```

## 环境搭建

### 方式一：使用Spring Boot（推荐）

#### 1. 创建Maven项目

在`pom.xml`中添加依赖：

```xml
<dependencies>
    <!-- YangMVC Spring Boot Starter -->
    <dependency>
        <groupId>org.docshare</groupId>
        <artifactId>yangmvc-spring-boot-starter</artifactId>
        <version>2025.07.06</version>
    </dependency>

    <!-- Spring Boot Web -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
    </dependency>

    <!-- MySQL Driver (如果使用MySQL) -->
    <dependency>
        <groupId>mysql</groupId>
        <artifactId>mysql-connector-java</artifactId>
        <version>8.0.33</version>
        <scope>runtime</scope>
    </dependency>
</dependencies>
```

#### 2. 配置数据库

在`application.yml`中配置：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/your_database?useUnicode=true&characterEncoding=utf8&useSSL=false
    username: root
    password: your_password
    driver-class-name: com.mysql.cj.jdbc.Driver

yangmvc:
  # 如果需要自定义配置
  template-base: /view/  # 模板文件路径
```

#### 3. 创建启动类

```java
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication

    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
```

## 重要配置：启用方法参数自动映射

### 什么是方法参数自动映射？

YangMVC支持将HTTP请求参数自动映射到控制器方法的参数中，让代码更简洁：

```java
// ❌ 传统方式：手动获取参数
public void login() {
    String username = param("username");
    String password = param("password");
    // ...
}

// ✅ 自动映射：参数直接注入
public void login(String username, String password) {
    // 直接使用参数，无需手动获取
}
```

### Maven配置（必需）

要在pom.xml中添加`-parameters`编译参数：

```xml
<build>
    <plugins>
        <plugin>
            <groupId>org.apache.maven.plugins</groupId>
            <artifactId>maven-compiler-plugin</artifactId>
            <version>3.8.1</version>
            <configuration>
                <source>1.8</source>
                <target>1.8</target>
                <encoding>UTF-8</encoding>
                <!-- 关键配置：保留参数名 -->
                <compilerArgs>
                    <arg>-parameters</arg>
                </compilerArgs>
            </configuration>
        </plugin>
    </plugins>
</build>
```

**注意**：如果不添加`-parameters`参数，方法参数自动映射功能将无法使用！

### 支持的参数类型

```java
// 字符串
public void demo(String name, String email) { }

// 整数
public void demo(Integer age, Integer page) { }

// 浮点数
public void demo(Double price, Double weight) { }

// 布尔值
public void demo(Boolean isActive, Boolean isDeleted) { }
```

### 使用示例

#### 示例1：用户登录
```java
// 请求: POST /user/login?username=admin&password=123456
public Map<String, Object> login(String username, String password) {
    Model user = Model.tool("user").get("username", username);
    if (user != null && user.getStr("password").equals(password)) {
        sess("user_id", user.get("id"));
        return Map.of("success", true, "message", "登录成功");
    }
    return Map.of("success", false, "message", "用户名或密码错误");
}
```

#### 示例2：分页查询
```java
// 请求: GET /user/list?page=1&pageSize=20&keyword=张三
public LasyList list(Integer page, Integer pageSize, String keyword) {
    int p = page != null ? page : 1;
    int size = pageSize != null ? pageSize : 20;

    LasyList users = Model.tool("user").all();
    if (keyword != null && !keyword.isEmpty()) {
        users = users.like("username", "%" + keyword + "%");
    }
    return users.orderBy("create_time DESC")
               .limit(size)
               .offset((p - 1) * size);
}
```

#### 示例3：添加用户
```java
// 请求: POST /user/save
// Content-Type: application/json
// Body: {"username": "张三", "email": "zhangsan@example.com", "age": 25}
public Map<String, Object> save(String username, String email, Integer age) {
    if (username == null || username.trim().isEmpty()) {
        return Map.of("success", false, "message", "用户名不能为空");
    }

    Model user = Model.tool("user").create();
    user.put("username", username);
    user.put("email", email);
    user.put("age", age);
    user.put("create_time", System.currentTimeMillis());
    user.save();

    return Map.of("success", true, "data", user);
}
```

### 混合使用

可以同时使用自动映射和手动获取参数：

```java
public void update(String username, String email) {
    // 自动映射的参数
    Model user = Model.tool("user").get("username", username);

    // 手动获取的参数
    Integer age = paramInt("age");
    String address = param("address", "未知");

    user.put("email", email);
    user.put("age", age);
    user.put("address", address);
    user.save();
}
```

### 返回值自动输出

方法参数自动映射配合返回值自动输出，代码更简洁：

```java
// 自动映射参数 + 自动返回JSON
public Map<String, Object> getUser(Integer id) {
    Model user = Model.tool("user").get(id);
    if (user == null) {
        return Map.of("error", "用户不存在");
    }
    return Map.of("success", true, "data", user);
}
```

### 注意事项

1. **必须添加`-parameters`编译参数**，否则功能无法使用
2. 参数名必须与HTTP请求参数名完全一致
3. 如果参数不存在，自动映射的参数值为`null`
4. 建议对可能为`null`的参数进行判空处理
5. 返回值会自动转换为JSON输出（Map、Model、List等）

## 快速开始

### 创建第一个控制器

```java
package org.example.controller;

import org.docshare.yangmvc.mvc.Controller;
import org.docshare.yangmvc.orm.Model;
import org.docshare.yangmvc.orm.LasyList;

public class BookController extends Controller {

    // 首页: http://localhost:8080/book/
    public void index() {
        put("title", "图书管理系统");
        renderFreeMarker("/book/index.html");
    }

    // 列表页: http://localhost:8080/book/list
    public void list() {
        LasyList books = Model.tool("book").all();
        put("books", books);
        put("total", books.size());
        renderFreeMarker("/book/list.html");
    }

    // 详情页: http://localhost:8080/book/detail?id=1
    public void detail() {
        Integer id = paramInt("id");
        if (id == null) {
            put("error", "参数错误");
            renderFreeMarker("/error.html");
            return;
        }

        Model book = Model.tool("book").get(id);
        if (book == null) {
            put("error", "图书不存在");
            renderFreeMarker("/error.html");
            return;
        }

        put("book", book);
        renderFreeMarker("/book/detail.html");
    }
}
```

## 核心概念

### 1. Controller（控制器）

所有控制器必须继承`org.docshare.yangmvc.mvc.Controller`类：

```java
import org.docshare.yangmvc.mvc.Controller;

public class HelloController extends Controller {

    public void index() {
        output("Hello, YangMVC!");
    }

    public void greeting() {
        String name = param("name"); // 获取参数
        output("Hello, " + name + "!");
    }
}
```

### 2. 参数获取

```java
public void demo() {
    // 获取字符串参数
    String name = param("name");
    String title = param("title", "默认标题"); // 带默认值

    // 获取整数参数
    Integer age = paramInt("age");           // 返回Integer，可能为null
    Integer page = paramInt("page", 1);      // 带默认值

    // 获取所有参数
    Map<String, String[]> paramMap = getParamMap();
}
```

### 3. 返回值自动输出

Controller方法支持返回值自动输出：

```java
// 返回字符串 - 直接输出文本
public String hello() {
    return "Hello, World!";
}

// 返回对象 - 自动转换为JSON
public Model getUser() {
    return Model.tool("user").get(1);
}

// 返回Map - 自动转换为JSON对象
public Map<String, Object> getInfo() {
    Map<String, Object> result = new HashMap<>();
    result.put("status", "success");
    result.put("message", "操作成功");
    return result;
}

// 返回集合 - 自动转换为JSON数组
public LasyList listUsers() {
    return Model.tool("user").all().limit(10);
}
```

```java
List<Model> userList = users.toArrayList();
```

## 控制器开发

### 完整的CRUD控制器

```java
package org.example.controller;

import org.docshare.yangmvc.mvc.Controller;
import org.docshare.yangmvc.orm.Model;
import org.docshare.yangmvc.orm.LasyList;
import java.util.HashMap;
import java.util.Map;

public class UserController extends Controller {

    // 用户列表
    public void list() {
        Integer page = paramInt("page", 1);
        int pageSize = 20;

        LasyList users = Model.tool("user").all()
            .orderBy("create_time DESC")
            .limit(pageSize)
            .offset((page - 1) * pageSize);

        long total = Model.tool("user").all().size();

        put("users", users);
        put("total", total);
        put("page", page);
        put("pageSize", pageSize);
        renderFreeMarker("/user/list.html");
    }

    // 新增页面
    public void add() {
        put("title", "添加用户");
        renderFreeMarker("/user/form.html");
    }

    // 保存用户
    public Object save() {
        Integer id = paramInt("id");
        String username = param("username");
        String email = param("email");
        Integer age = paramInt("age");

        // 验证
        if (username == null || username.trim().isEmpty()) {
            return error(400, "用户名不能为空");
        }

        Model user;
        if (id != null && id > 0) {
            // 更新
            user = Model.tool("user").get(id);
            if (user == null) {
                return error(404, "用户不存在");
            }
        } else {
            // 新增
            user = Model.tool("user").create();
            user.put("create_time", System.currentTimeMillis());
        }

        user.put("username", username);
        user.put("email", email);
        user.put("age", age);
        user.put("status", "active");
        user.save();

        return success("保存成功", modelToMap(user));
    }

    // 编辑页面
    public void edit() {
        Integer id = paramInt("id");
        Model user = Model.tool("user").get(id);

        if (user == null) {
            put("error", "用户不存在");
            renderFreeMarker("/error.html");
            return;
        }

        put("user", user);
        put("title", "编辑用户");
        renderFreeMarker("/user/form.html");
    }

    // 删除用户
    public Object delete() {
        Integer id = paramInt("id");
        if (id == null) {
            return error(400, "ID不能为空");
        }

        int affected = Model.tool("user").del(id);
        if (affected > 0) {
            return success("删除成功");
        } else {
            return error(404, "用户不存在");
        }
    }

    // 辅助方法：成功响应
    private Map<String, Object> success(String message) {
        Map<String, Object> result = new HashMap<>();
        result.put("status", "success");
        result.put("message", message);
        return result;
    }

    private Map<String, Object> success(String message, Object data) {
        Map<String, Object> result = new HashMap<>();
        result.put("status", "success");
        result.put("message", message);
        result.put("data", data);
        return result;
    }

    // 辅助方法：错误响应
    private Map<String, Object> error(int code, String message) {
        Map<String, Object> result = new HashMap<>();
        result.put("status", "error");
        result.put("code", code);
        result.put("message", message);
        return result;
    }

    // 辅助方法：Model转Map
    private Map<String, Object> modelToMap(Model model) {
        if (model == null) return null;
        Map<String, Object> map = new HashMap<>();
        for (String key : model.keySet()) {
            map.put(key, model.get(key));
        }
        return map;
    }
}
```

### 分页示例

## API开发

### RESTful API示例

```java
package org.example.controller;

import org.docshare.yangmvc.mvc.Controller;
import org.docshare.yangmvc.orm.Model;
import org.docshare.yangmvc.orm.LasyList;
import java.util.HashMap;
import java.util.Map;

public class ApiUserController extends Controller {

    // GET /api/user/users - 获取用户列表
    public Object users() {
        Integer page = paramInt("page", 1);
        Integer pageSize = paramInt("pageSize", 20);

        LasyList users = Model.tool("user").all()
            .orderBy("create_time DESC")
            .limit(pageSize)
            .offset((page - 1) * pageSize);

        Map<String, Object> result = new HashMap<>();
        result.put("status", "success");
        result.put("data", users.toArrayList());
        result.put("total", users.size());
        result.put("page", page);
        return result;
    }

    // GET /api/user/get?id=1 - 获取单个用户
    public Object get() {
        Integer id = paramInt("id");
        if (id == null) {
            return error(400, "ID参数不能为空");
        }

        Model user = Model.tool("user").get(id);
        if (user == null) {
            return error(404, "用户不存在");
        }

        return success(user);
    }

    // POST /api/user/create - 创建用户
    public Object create() {
        String username = param("username");
        String email = param("email");
        Integer age = paramInt("age");

        if (username == null || username.trim().isEmpty()) {
            return error(400, "用户名不能为空");
        }

        Model user = Model.tool("user").create();
        user.put("username", username);
        user.put("email", email);
        user.put("age", age);
        user.put("create_time", System.currentTimeMillis());
        user.put("status", "active");
        user.save();

        return success("创建成功", user);
    }

    // POST /api/user/update - 更新用户
    public Object update() {
        Integer id = paramInt("id");
        if (id == null) {
            return error(400, "ID参数不能为空");
        }

        Model user = Model.tool("user").get(id);
        if (user == null) {
            return error(404, "用户不存在");
        }

        String username = param("username");
        String email = param("email");
        Integer age = paramInt("age");

        if (username != null) {
            user.put("username", username);
        }
        if (email != null) {
            user.put("email", email);
        }
        if (age != null) {
            user.put("age", age);
        }

        user.save();
        return success("更新成功", user);
    }

    // POST /api/user/delete - 删除用户
    public Object delete() {
        Integer id = paramInt("id");
        if (id == null) {
            return error(400, "ID参数不能为空");
        }

        int affected = Model.tool("user").del(id);
        if (affected > 0) {
            return success("删除成功");
        } else {
            return error(404, "用户不存在");
        }
    }

    // 辅助方法
    private Map<String, Object> success(Object data) {
        Map<String, Object> result = new HashMap<>();
        result.put("status", "success");
        result.put("data", data);
        return result;
    }

    private Map<String, Object> success(String message, Object data) {
        Map<String, Object> result = new HashMap<>();
        result.put("status", "success");
        result.put("message", message);
        result.put("data", data);
        return result;
    }

    private Map<String, Object> error(int code, String message) {
        Map<String, Object> result = new HashMap<>();
        result.put("status", "error");
        result.put("code", code);
        result.put("message", message);
        return result;
    }
}
```

```java
public void save() {

    String username = param("username");

        return;
    }

    // 格式验证
    String email = param("email");

        return;

    // 业务逻辑验证
    Model existing = Model.tool("user").get("username", username);

        return;
    }

    // 保存数据
    Model user = Model.tool("user").create();
    user.put("username", username);
    user.put("email", email);
    user.save();

    outputJSON(ApiResponse.success(user));
}
```

```java
public void transfer() {
```
